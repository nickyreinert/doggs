      Categories

      Every document is filed into exactly one of these. One category per line; both the fast classifier and the LLM choose from this list.

      Rules

      Checked top to bottom while processing; the first enabled rule whose conditions all match sets the category and adds tags. Leave a condition empty to skip it.

      API & MCP

      A read-only API and MCP server so tools like Claude can search your archive. Enabled by setting EXTERNAL_API_TOKEN in the server's .env.

      Access

      Replace $DOGGS_TOKEN with the token from the server's .env. Claude Desktop: see mcp_stdio.py in the README.

      Search index

      API results include this URL plus the archive-relative path so clients can open the original file. Sharing must be enabled on the host.
