    These folders and defaults were set via .env or built-in defaults. Fields marked as locked are set by an environment variable and can't be changed here.


    Ignored inferred tags are hidden from tag lists and document headers. Custom tags are never removed.

    One category per line. The LLM must assign every processed document to one of these categories.

    Rules run top to bottom during processing; the first enabled rule whose conditions all match sets the category and adds tags. Leave a condition blank to skip it.

    External integrations use the same server port as DOGGS and require the EXTERNAL_API_TOKEN environment variable.

    The API returns this network URL plus the archive-relative file path. SMB sharing must be enabled separately on the host.

    Document text is appended automatically. Keep the metadata response JSON-compatible.

    Use one or more 24-hour times, separated by commas.
